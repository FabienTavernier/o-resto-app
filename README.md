# O'resto – React Native

⚠️⚠️⚠️ **Fichier temporaire** ⚠️⚠️⚠️

Expo ne permet la création d'un nouveau projet dans un dossier non vide 😢

L'idée est donc la suivante :

1. crée un projet Expo à partir d'ici ; par défaut, ça sera dans un dossier `my-app/`
2. déplace tous les dossiers/fichiers de `my-app` vers ici (à la racine)[*]

Bien entendu ce fichier disparaîtra, ou plutôt sera remplacé par le README d'Expo ♻️

Mais ne t'inquiète pas : on a prévu un fichier
[LISEZ_MOI](./LISEZ_MOI.md) pour la présentation du projet et les énoncés 🧠

> [*] pourquoi cette étape ? Pour Biome notamment…
> et parce que, personnellement, je préfère avoir mon code à la racine…
